## 🧬 Architecture Overview

For the technically inclined, here's the shape of the thing.

The companion consists of four cooperating layers:

1. **The Observer Layer** — passively watches the running game process, gathering read-only signals about world state. It never writes to game memory during this phase.
2. **The Interpretation Layer** — translates observer signals into the semantic vocabulary described above (Tempo, Resilience, Abundance, and so on).
3. **The Presentation Layer** — renders the overlay UI, handles hotkeys, and manages visual themes.
4. **The Application Layer** — applies your chosen adjustments, but only when explicitly enabled, and only within the session's memory space.

This layered design means each piece can be reasoned about independently. If the overlay stops responding, the Observer is likely fine — the problem is probably in Presentation. This separation is deliberate and it makes troubleshooting dramatically more tractable.

## 🧯 Troubleshooting — When the Fog Refuses to Lift

Every tool meets resistance eventually. Here are the most common encounters and their resolutions.

### The overlay doesn't appear
Ensure the game is running in a windowed or borderless-windowed mode. Exclusive fullscreen can obscure overlay rendering on some driver configurations. Also verify the companion launched before the game.

### The overlay appears but hotkeys do nothing
Another application may have claimed the same key combination. Open the settings panel and reassign hotkeys to less contested bindings. Streaming software and chat clients are frequent culprits.

### Performance feels diminished
Disable the least-used visual theme effects (blur, glow, animation). The overlay itself is lightweight, but every millisecond matters on older hardware.

### Adjustments reset when I close the game
This is by design — see the *Non-Destructive Operation* feature above. Save a profile if you want persistence.

### Windows Defender raises a flag
Some defensive systems treat any tool that observes another process as suspicious by category rather than by action. Add the companion folder to your allow list after reviewing its contents. A read of the source documents what it does and why.

### Antivirus quarantines the executable on first run
Restore it from quarantine and whitelist the folder. Then verify the package integrity against the checksums published in the repository's releases documentation.
